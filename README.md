# Akademi Listrik & Elektronika

Website pembelajaran listrik untuk pemula, menggunakan Next.js, TypeScript, Tailwind CSS, dan materi MDX.

## Menjalankan

```bash
npm install
npm run dev
```

Kunjungi http://localhost:3000.

## Fitur
- Dashboard dan katalog 24 modul
- Materi dasar listrik berbasis MDX
- Simulator Hukum Ohm
- Kuis interaktif
- Progress tersimpan di browser

> Semua simulasi bersifat pendidikan. Jangan melakukan eksperimen pada instalasi PLN yang bertegangan.
