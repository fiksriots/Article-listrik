<LearningHook>Setelah tombol START dilepas, bagaimana mesin tetap berjalan sampai STOP ditekan?</LearningHook>

## 1. Mengingat perintah dengan kontak bantu
Bayangkan pintu yang terbuka sesaat lalu ditahan pengait. Tombol START NO memberi perintah awal. Ketika koil kontaktor aktif, kontak bantu NO menutup dan mempertahankan jalur koil. Kontak pengunci dipasang paralel dengan START dalam konsep kontrol ini; STOP NC dan kontak overload berada di jalur seri.

## 2. Ikuti perubahan keadaannya
| Kejadian | Kontak pengunci | Koil |
|---|---|---|
| Awal, suplai tersedia | Terbuka | OFF |
| START ditekan, STOP/overload normal | Menutup | ON |
| START dilepas | Tetap tertutup | Tetap ON |
| STOP ditekan atau overload membuka | Membuka setelah koil lepas | OFF |
| Suplai hilang | Kembali terbuka | OFF |
| Suplai kembali, START dilepas | Tetap terbuka | Tetap OFF dalam model ini |

## 3. Overload berbeda dari pengaman hubung singkat
Kontak bantu overload dapat membuka jalur koil saat trip. Overload bukan pengganti pemutus hubung singkat. Penempatan pengaman, kategori kontaktor, tegangan koil, serta koordinasi starter memerlukan desain yang sesuai. Tombol STOP biasa bukan pengganti isolator atau emergency stop tersertifikasi.

## Studi kasus: Kontaktor hanya aktif selama START ditekan
Dalam model latihan, kemungkinan jalur pengunci tidak tersambung atau kontak yang dipilih bukan NO yang benar. Periksa diagram dan keadaan simulasi dahulu. Jangan menjumper STOP atau overload pada mesin nyata untuk membuatnya tetap berjalan.

## 4. Coba simulator di bawah
Tekan START, lepaskan, kemudian STOP. Coba overload dan putuskan suplai. Reset overload tidak menjalankan motor; perlu START baru. Simulator hanya menggambarkan logika koil, bukan arus motor, kegagalan kontak, rangkaian keselamatan, atau panduan wiring.
